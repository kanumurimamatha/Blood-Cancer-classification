# Blood Cancer Classification using EfficientNet-B0

## Overview
This project presents a deep learning model for blood cancer classification using EfficientNet-B0. It classifies microscopic blood smear images into four categories of Acute Lymphoblastic Leukemia (ALL).

## Technologies Used
- Python
- TensorFlow
- Keras
- EfficientNet-B0
- OpenCV
- NumPy
- Matplotlib

## Features
- Blood cancer cell classification
- Image preprocessing
- Transfer Learning
- Deep Learning model
- High prediction accuracy

## Project Information
This project was developed as my Final Year Engineering Project.

## Results
- Validation Accuracy: **98.92%**
- Four-class classification of blood cancer cells
